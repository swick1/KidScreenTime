What this app actually does to your PC

Specifics, not reassurance — so you can check my work instead of trusting my word.

If you don't know me personally, "trust me, it's safe" isn't worth much. This tool listens to your microphone and installs a keyboard hook — those are exactly the kinds of things antivirus software is built to be suspicious of, and honestly, you should be a little suspicious too. So here's exactly what's in it, in plain terms, so you (or your antivirus, or anyone who wants to read the code) can verify it instead of taking my word for it.

No network activity, anywhere

There is no networking code in this app at all — no HTTP requests, no analytics, no "phone home" on startup, nothing. Everything it does happens entirely on your machine. That's not a policy I promise to follow; it's an absence of code, which is checkable in the source itself, or by watching the app in any network monitor and seeing nothing leave your machine.

The keyboard hook doesn't see what you type

The app installs a low-level keyboard hook, and I want to be specific about exactly what that means, because "keyboard hook" understandably sounds like "keylogger." It isn't one. The hook only ever looks at two things: which specific control key was pressed (to catch things like Alt+Tab or the Windows key while the lock screen is up), and the timestamp of the most recent keypress (to avoid mistaking a loud mechanical keyboard for a kid yelling — see below). It never converts a keypress into an actual letter or character, never logs anything to disk, and never sends anything anywhere. There is no code path in this app that could reconstruct what you typed, in this app or any other.

The microphone only measures loudness, never records

Frustration detection listens to raw volume levels — is the room suddenly and sharply louder than normal — not speech content. Nothing is transcribed, recorded, or saved to disk at any point. It's the same as a sound meter: it looks at a number, decides if that number is unusual, and forgets it a moment later.

What actually gets installed on your computer

WhatWhereWhy
The app itself %LocalAppData%\Programs\KidScreenTime A per-user folder — the installer never asks for admin rights, because it doesn't need them.
Your settings/schedule %AppData%\KidScreenTime\config.json Plain JSON, human-readable, yours to open and inspect any time. Your password is stored as a salted hash, never in plain text.
Two Run-key entries HKCU\...\Windows\CurrentVersion\Run So the app (and a small watchdog that relaunches it if it's closed) start when you log in. Both are per-user (HKCU), not machine-wide.

All of it is per-user, not system-wide — nothing here touches Program Files, no service is installed, and no other Windows account on the machine is affected.

Why it fights back a little

The watchdog process and the Run key entries exist for one reason: so a kid can't just close the app and go back to unrestricted screen time. That same behavior is exactly what antivirus heuristics are trained to flag — a background process that relaunches something if it's closed looks, on paper, identical to malware persistence. I'd rather tell you that up front than have you find out from a scary AV popup. There's an override password set up at install time specifically so you're never locked out of your own computer — it's built to resist a kid clicking around it, not to resist you.

If your antivirus flags the installer: that's a heuristic match on "background process, restarts itself, hooks the keyboard" — a pattern, not a verdict on the actual code. You're welcome to read the source yourself, or submit the file to your antivirus vendor's false-positive review process.
